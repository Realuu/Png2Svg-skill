# 重建与校准方法

## 坐标、共享定义与绘制

以原图像素建立坐标系，先记录框边界和连线端点，再放文字。不要凭视觉重新排版后才试图靠整体缩放贴合原图。渐变、箭头 `marker`、可复用符号放在 `defs`，所有分区采用唯一 ID 前缀。线与箭头头部的颜色应逐一核对，不能默认 marker 继承父元素颜色。检查 `markerUnits`、端点偏移和线宽对尖端的影响。

组装时显式处理跨区连线。例如标题条在背景框之上，而输出箭头可能应在标题条之上；分区绘制正确不代表合成后的遮挡正确。

图标需要保留其轮廓、构件、数量与状态差异，这些都属于图示内容。不要用大致相似的 Unicode emoji 替代需要精确保真的小图标。

## 可编辑文字与数学公式

先核对字体实际安装情况和真实字重文件，再设置文本。坐标相同但字体回退，会使宽度、基线和排版明显改变。可以测量字形边界与 advance；先修正字号、锚点、换行，再考虑小幅横向缩放。大量强制缩放常常说明字体匹配错误。

必要时将每个标签渲染为独立透明图，与原图局部做轻微平移/缩放配准。优化变量只作用于几何位置，限制变动范围并比较前后结果。低对比背景、同色曲线、邻近标签会污染损失函数；自动结果不得无条件套用。

SVG 属性区分大小写：`viewBox`、`textLength`、`lengthAdjust`、`preserveAspectRatio`。通用 Python 辅助函数把下划线改为连字符时，会错误生成 `text-length`。即便属性正确，渲染器对文本宽度控制也可能不同；必要时采用标准 `translate`/`scale` 包裹文字，并在目标编辑器中验证。

公式宜用多个 `tspan` 表示基线与字号，或者使用可靠的数学排版输出，并单独保留可编辑源码。核对普通字母 i 与下标 i、横排星号与上标星号、× 与 x、τ 与 t 等。文本读取顺序相同不能证明上下标位置正确。

## 曲线重建

处理清晰的彩色曲线时，可在局部 ROI 内：

1. 按颜色距离、饱和度和明度识别候选像素，排除轴线、同色标题和图例。
2. 提取折线关键点或沿列/法线估计中心线；标记点可能比线更粗，要区分两者。
3. 对连续密度边界等使用受控样条，再转换为三次 Bézier；对真实折线保留转折，避免过度平滑。
4. 在原图上叠加检查路径、极值、分支、端点、填充闭合和小圆点。

若自动提取存在相邻结构混入，缩小 ROI 或人工修正关键点通常比增加全局阈值更可靠。这里得到的是图形几何近似，没有恢复底层数据的精度保证。

## 文字转曲的边界

适用编辑器可直接完成文本转路径。需要代码转换时，FontTools `TTFont` 和 `SVGPathPen` 可读字体轮廓，但它们本身不是完整文本排版引擎：

- 显式解析字体家族、实际字重/斜体文件、Unicode 映射、advance 和字距。
- 应用锚点、继承字号、`tspan` 的 `x/y/dx/dy`、基线偏移和父级 transform。
- 对复杂文字、连字、双向排版、可变字体等使用支持 shaping 的排版引擎，或者调用可靠编辑器；不要静默用简单逐字路径拼接。
- 对缺字和不支持的文本属性中止该次转曲，回到可编辑母版修复。可用三个矢量圆点表示无相应字形的省略号，但要按原图确认间距与位置。
- 保留语义映射；同一字形可放入 `defs` 并用 `use` 复用，以控制文件体积。
- 重渲染转曲版对照母版，不能只验证没有 `text` 标签。

## 自动描摹何时可用

孤立单色图标、封闭轮廓可尝试阈值描摹；多色渐变、小字、密集虚线不适合直接套用全图自动描摹。评估应看放大后曲线是否平滑、细笔画是否完整、是否产生多重彩色边缘，以及后续是否能够有效编辑。

若自动描摹不合适，及时改用字体与图元重建。对特定软件的一次失败，不应推断其在所有图片上都无效。
