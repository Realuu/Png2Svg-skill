# 通用流程复盘：复杂图示的 PNG 到 SVG 重建

本文把一次图示重建任务整理为可复用流程。示例仅描述通用方法，不记录特定图片的文字、尺寸、数值、实验数据、作者信息或研究结论。新任务的图像内容只用于完成该次委托，不应复制进通用技能文档。

## 工作流程

1. **确认输入与交付目标。** 查看原图及清晰度，记录本次画布比例和用户要求。确认需要可编辑文字、文字转曲副本、预览图或对照页中的哪些交付物。
2. **独立登记内容。** 按视觉区域清点标题、标签、公式、容器、连线、图表、标记、图标和边缘内容；保存为本次任务的清单。记录模糊项和重复次数，不把 OCR 输出当作最终核对结果。
3. **确定矢量重建策略。** 对文字和结构清晰的图形优先使用 SVG 原生元素；对边界明确的局部图形，可先试小范围自动描摹并放大检查。不要只凭整图相似度决定描摹质量。
4. **按层次重建。** 先建立画布与主要区域，再添加容器、连线、曲线、图标和文字。复杂图按独立区域划分文件或模块，并约定共享坐标、样式、ID 前缀和合成顺序。
5. **保留文字与数据语义。** 可编辑母版使用真实 SVG 文本并校对字体、换行、上下标和符号。由示意图估计的曲线点只代表视觉近似，不应称为原始实验数据。
6. **逐项对照。** 将渲染结果与原图按相同比例叠加或滑动比较，检查全图和放大局部。依据清单核对内容、连接关系、层叠、字体、曲线形状及边缘元素；自动结构检查与人工视觉检查分别记录。
7. **导出并复核。** 保存可编辑 SVG；用户需要时另存转曲副本。对最终文件运行结构检查、重新渲染并复查，确认转曲前后布局一致。对照 HTML 可能包含原图，分享前检查其中是否嵌入源图。

## 常见失误与处理

| 现象 | 建议处理 |
|---|---|
| 全图自动描摹造成文字碎裂、噪点或文件过大 | 先局部试验；文字密集区域改用可编辑文本，描摹只用于适合的局部 |
| 曲线提取混入坐标轴、标记或邻近图形 | 缩小处理区域，结合颜色和几何约束，并叠加到原图检查 |
| 字体回退造成宽度、基线或换行变化 | 检查目标字体和实际字重，先校准字号与换行，再做位置微调 |
| 总数正确但内容仍有遗漏或遮挡 | 按清单逐项检查可见性、所在区域和连接关系，不用计数替代视觉核查 |
| 转曲文件与可编辑版显示不同 | 使用目标渲染器复核转换结果，并保留可编辑母版作为后续修改来源 |
| 预览看似一致但局部细节失真 | 检查放大局部中的小字、细线、标记、箭头尖端和边缘内容 |

## 可复用原则

- 每个任务单独保存参考图、清单、中间文件和交付物；通用技能仓库只保留方法、工具和不含来源细节的示例。
- 不把某张图的具体标签、尺寸、计数、颜色阈值、坐标、字体路径或识别结果写成默认值。
- 结论只描述实际运行和查看过的检查；结构可解析、内容完整和视觉接近是不同判断。
- 修改先回到可编辑母版，再重新生成所有派生文件与核查报告。
